## Current

### Backfill

- **Backfill has an API, CLI dry runs and UI progress** (D363): POST /api/v1/dags/{id}/backfills
  returns the backfill ID and created/skipped run counts; GET /api/v1/backfills/{id} returns run
  counts by state. `schedr runs backfill --dry-run` counts without creating runs. The DAG page has a
  Backfill form and displays progress.
- **Backfill runs are ordered oldest first** (D364): Backfill runs are always ordered oldest first;
  no newest-first ordering is offered.
- **A backfill skips fire times with a successful or unfinished run** (D400): By default a backfill
  creates a run only for a fire time with no successful, queued or running run for that
  `planned_for` (of any kind), so a day isn't run twice at once; `--all` creates one for every fire
  time.
- **A backfill's runs start on a paused DAG** (D401): A backfill is a person's request, as a manual
  run is: its runs start on a paused DAG, waiting only for `max_active_runs`. Pausing switches off
  the DAG's trigger only (decision 398).
- **Cancelling a backfill cancels its queued and running runs** (D402): `schedr runs cancel
  --backfill <id>` cancels every unfinished run of the backfill: queued ones at once, running ones
  stopped as `schedr runs cancel` stops a run. Finished runs stay as they are.
- **A backfill's progress shows on its runs and on the DAG page** (D403): Each backfill run's label
  says `backfill 3/31` (its place among the backfill's runs, oldest first). The DAG page lists its
  backfills with their runs' counts by state and a Cancel button.
- **A backfill works on any trigger with fire times** (D404): A backfill takes a DAG whose trigger
  has fire times: `Cron` (its presets included), `Every` and `Once` (a single run). A DAG with
  `trigger=None`, `Chained()`, an event trigger, `RunOf` or `EventNamed` has none, and a backfill of
  it is refused.
- **The scheduler skips fire times another run covers** (D405): The scheduler creates no scheduled
  run for a fire time with a successful, queued or running run of any kind (a backfill's, a manual
  one): D400's rule the other way, so a period isn't run twice. Covered fire times take no place,
  and with `catchup` the ones after them follow. A covering run that fails later leaves its day
  without a scheduled run: it is rerun by hand.
