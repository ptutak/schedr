## Current

### run_dag

- **TaskResult output is typed as object** (D73): `run_dag` exposes `TaskResult.output` as `object`,
  so a test narrows it before using fields. `output_json` uses the `Json` type.
- **run_dag exposes mapped instances under the task result** (D85): `result.tasks["fetch"]`
  represents the whole task and its output is the gathered list. Indexing that result or using
  `.instances` accesses individual instance results.
- **Testing one DAG file parses that file alone** (D117): When dags test selects a file, its
  directory is the root but only that file is parsed. Imports from sibling files still work; the
  internal selection is not configurable.
