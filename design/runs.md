## Current

### Backfill

- **Backfill has an API, CLI dry runs and UI progress** (D363, planned (M4.12b)): POST
  /api/v1/dags/{id}/backfills returns the backfill ID and created/skipped run counts; GET
  /api/v1/backfills/{id} returns run counts by state. `schedr runs backfill --dry-run` counts
  without creating runs. The DAG page has a Backfill form and displays progress.
- **Backfill runs are ordered oldest first** (D364, planned (M4.12b)): Backfill runs are always
  ordered oldest first; no newest-first ordering is offered.
