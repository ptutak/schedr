## Current

### Async tasks

- **Async task calls return coroutines outside a DAG** (D49): Outside a DAG, a plain async task call
  returns a coroutine; typed tests use `await task.fn(...)`, since a plain call is typed as its
  result. Async cleanups and resource setups/cleanups are supported. Remaining background tasks are
  cancelled; their errors are warnings and do not change the attempt’s result.
- **Async tasks and watcher hosts use uvloop whenever installed** (D316): The interpreter uses
  uvloop when it can import it; otherwise it uses asyncio. Each async attempt logs its loop, and
  schedr[uvloop] offers an installation extra.
- **Tests await an async task through its fn attribute** (D319): await task.fn(...) calls the
  coroutine with the task’s declarations in force. Its type is the function’s return type, including
  None; wrapped functions retain their kind.
