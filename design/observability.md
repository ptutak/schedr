## Current

### Metrics and logs

- **Concurrency waiting reasons name the limit and value** (D91): A waiting reason names the reached
  concurrency limit and its value. `master_tasks_waiting` labels these waits by the limit’s name.
- **The UI shows watcher hosts and switched-off sensors** (D343): The Workers page and metrics show
  each host’s code hash, wait steps, threads, memory and losses. The DAG page lists switched-off
  sensors with switch-on; the DAGs list shows their count.

### Operational views

- **Record leader and standby masters with heartbeats** (D123): Each running master heartbeats a
  masters table row with its role and configuration. A master that stops reporting ages out.
- **Show node problems on the Deployments graph** (D129): Warnings colour nodes yellow and errors
  red; panels list current problems. Unreachable webservers are errors and version mismatches
  warnings; masters report current problems in heartbeats. Lost workers are errors, while
  disconnected workers, reported warnings and import errors produce warnings. Offline workers have
  no problems and remain grey and dashed, ignoring stale warnings and import errors.
