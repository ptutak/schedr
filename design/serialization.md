## Current

### Pydantic

- **Pydantic JSON Schema describes model types** (D59): Pydantic model descriptors store JSON
  Schema: serialization schemas with all fields required for outputs, validation schemas for
  parameters. Python compares these with model, dataclass and plain types; Rust stores them.
  Compatibility requires proof that every output value is accepted; uncomparable constructs require
  identical schemas, references are followed, and errors name the field and constraints.
- **Pydantic dates interoperate with schedr date types** (D60): Pydantic date/datetime/duration text
  and schedr’s corresponding tagged types fit each other both ways; the runner converts through
  Pydantic’s parsing and JSON validation. Plain strings do not fit date types without the
  appropriate schema format. A model’s naive datetime stays naive when read, but schedr refuses it
  when subsequently storing it as its own datetime, advising `AwareDatetime` or an explicit zone.
- **Read Pydantic models back using JSON validation** (D111): The runner validates stored model data
  with model_validate_json. Schedr tags in the data are first written in Pydantic's JSON
  representation.

### Stored values

- **Schedr refuses to store naive datetimes** (D63): A naive datetime passed on from a Pydantic
  model is refused when schedr stores it. The error suggests `AwareDatetime` or adding a time zone.
- **Escape user dictionaries shaped like serialization tags** (D104): A user dict whose sole key is
  a serialization tag is stored inside a $dict escape. Output paths and literal dictionaries
  containing references pass through the escape.
- **Stored numbers round-trip exactly within the 64-bit integer range** (D105): Floats round-trip to
  the same bits; integers outside -2**63 through 2**64 - 1 fail where written. The integer limit
  also applies to Literal integers and timedelta microseconds.
- **Reject NUL in stored output strings and dictionary keys** (D106): The runner fails an attempt
  when an output string or dictionary key contains NUL. The error identifies the value at encoding
  time.
- **Replace NUL in command output text with U+FFFD** (D110): The agent replaces NUL in ProcessResult
  stdout and stderr with U+FFFD. The log file keeps the original bytes.
- **Build structures containing references as the parameter's type** (D112): Structured arguments
  containing references are built recursively as the parameter’s type. A union uses the first
  fitting member of the same shape; when only one member has that shape, its literals are checked at
  parse time. Missing or refused fields fail the attempt with input_mismatch.
