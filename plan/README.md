# schedr: the plan

The milestones and their steps, in order, with each step's state. This page is generated by
`make records` from `plan/<milestone>.toml`: it is an index. A step's scope and
"done when", and a milestone's notes, are in its milestone's file; the reasons are in
JOURNAL.md (in `archive/PROJECT.md` before decision 367). The plan's general notes (the M1 scope, workspace layout, library choices, testing
approach) are in `plan/notes.md`. A step's decisions are those whose `step` names it.

To change the plan: edit `plan/<milestone>.toml` (a step's `status` becomes `done` with its
`done` date and `commits` when it is committed), then `make records`.
